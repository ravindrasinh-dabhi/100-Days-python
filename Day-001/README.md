## ⚡ Practical Project: Electrical Lab Reading Inspector

### Problem Statement
Create a Python program to manage electrical laboratory current measurements using lists.

### Initial Data
```python
readings = [2.1, 2.4, 2.2, 2.8, 2.5]
```

### Tasks Completed
- Printed first and last readings.
- Updated the third reading from 2.2 to 2.3.
- Added a new reading of 2.6.
- Removed the invalid reading of 2.8.
- Calculated the total number of readings.
- Calculated total current using a for loop.
- Calculated average current.
- Counted readings greater than 2.4.

## 💻 Final Output

```text
First reading: 2.1
Last reading: 2.5

Final readings: [2.1, 2.4, 2.3, 2.5, 2.6]
Total readings: 5

Total current: 11.90
Average current: 2.38
Readings above 2.4: 2
```
