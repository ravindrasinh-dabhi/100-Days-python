## ⚡ Practical Project: Electrical Voltage Data Analyzer

### Problem Statement

Analyse 10 voltage measurements recorded during an electrical laboratory experiment using Python list indexing and slicing.

### Initial Data

```python
voltage = [218, 220, 222, 225, 228, 230, 233, 235, 238, 240]
```

### Tasks Completed

- Printed the first five voltage readings.
- Printed the last three voltage readings.
- Extracted readings from index 2 to index 6.
- Printed every alternate voltage reading.
- Reversed the complete list using slicing.
- Printed the third and second-last readings.
- Extracted the middle four readings.

## 💻 Final Output

```text
First five voltage readings: [218, 220, 222, 225, 228]
Last three voltage readings: [235, 238, 240]
Selected readings: [222, 225, 228, 230, 233]
Alternate readings: [218, 222, 228, 233, 238]
Reversed readings: [240, 238, 235, 233, 230, 228, 225, 222, 220, 218]
Third reading: 222
Second-last reading: 238
Middle four readings: [225, 228, 230, 233]
```
